# AX Festival UI 작업 계약

이 지침은 이 패키지를 사용하는 AX Festival UI 범위에 적용한다. 명시적인 사용자 지시가 가장 우선한다.

- 반드시 DESIGN-CONTRACT.md, PAGES.md, QA.md와 대상 reference/screens 이미지를 읽는다.
- design-system, assets, reference, lock.json은 동결된 입력이다. 기능 작업 중 수정하지 않는다.
- 새 UI는 하나의 검수 대상 폴더에 모은다. 공유 컴포넌트도 검사 범위에 포함한다.
- UI 시각 스타일은 design-system/tokens.css 및 components.css만 사용한다. 다른 CSS, CSS-in-JS, 인라인 style, 임의 유틸리티, 외부 테마 주입 금지.
- 구현은 의미 있는 HTML과 공통 컴포넌트 조합으로 한다. 이미지 한 장으로 전체 UI를 구현하지 않는다.
- 새 색, 자간, 폰트, 그림자, 그라데이션, 반경, 아이콘 세트, 메뉴, 페이지 추가는 별도 변경안으로 기록한다.
- 원본 기능/API/인증/검증을 추정으로 바꾸지 않는다. 예시 이름·수치·신청 상태는 데이터로 대체한다.
- unresolved 기능은 앱의 기존 구현과 정책을 확인하되, 정책·화면을 추정 생성하지 않는다.
- 테스트를 통과시키려고 기준 파일, 검사기, lock.json 또는 캡처 기준을 변경하지 않는다.
- 각 페이지마다 디자인 검사, 실제 화면 비교, 키보드 및 오류 경로 확인을 수행한다.
- 디자인 변경이 명시적으로 승인되면 새로운 버전으로 규칙·코드·기준 이미지·lock을 함께 업데이트하고 변경 기록을 남긴다.
