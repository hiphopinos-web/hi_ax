# 디자인 계약 · AX-TDS-2026.09.21-v1

## 1. 기준과 충돌 해결

기준은 Figma `2858:8`의 2026-09-21 추출본이다. 이 패키지의 이미지/JSON은 시점 고정 스냅샷이며 Figma의 이후 편집을 자동 반영하지 않는다. `AX TDS/*` 스타일과 `VariableID:2858:*`만 사용한다. `AX UI 제안/*`, 초기 `2846:*` Material 토큰, 발표용 블랙 배경은 앱에 섞지 않는다. TDS에서 영향을 받은 **AX의 커스텀 시스템**이며 Toss 공식 컴포넌트 패키지를 그대로 구현했다는 의미는 아니다.

실제 화면별 재정의가 컴포넌트 원본보다 우선한다. 대표적으로 로그인은 TextField/Default 라이브러리에 있는 외부 라벨/도움말을 사용하지 않고 실제 A01의 56px 필드만 사용한다. 이미지와 규칙이 충돌하면 해당 화면만 확인 항목으로 기록한다.

## 2. 정보 구조

하단 최상위 메뉴는 `홈 / 프로그램 / 체험 / 나의 참여` 순서로 고정한다. 스탬프·보상·내 일정은 나의 참여의 하위 목적지다. QR은 유틸리티이며 다섯 번째 탭이 아니다. 홈은 현재 할 일, 프로그램은 탐색/신청, 체험은 활동 시작, 나의 참여는 개인 기록에 집중한다. 상세 화면에 전체 목록/보상/프로필을 다시 몰아넣지 않는다.

한 화면의 주 행동은 하나다. 보조 행동은 Weak 버튼/텍스트로 구분한다. 신청은 상세 → 확인 → 결과 → 내 일정으로 이어진다. 자유 입장 프로그램에 신청 버튼을 추가하지 않는다. 최신 P01 필터는 `전체 / 강연 / 실습 / 상담`이다. 층수는 목록의 정보 배지이며 필터 탭으로 바꾸지 않는다.

## 4. 색상 역할

실제 값은 tokens.json/tokens.css를 따른다. 색상 이름이 아니라 의미 토큰을 호출한다.

| 역할 | 토큰 | 규칙 |
|---|---|---|
| 화면 바탕 | canvas | 회색 그룹 배경 |
| 카드/기본 페이지 | surface | 흰색 |
| 입력·내부 정보 | inset | 아주 옅은 회색 |
| 제목/본문/메타 | ink / body / muted | 위계를 크기·굵기와 함께 표현 |
| 주 행동 | brand + onBrand | 오렌지 배경에 짙은 글자. 흰 글자로 변경 금지 |
| 보조 행동 | brandSoft + brandText | 약한 오렌지 바탕 또는 강조 텍스트 |
| 분류 | purpleSoft + purpleText | 프로그램 분류 등 기준 화면에 한정 |
| 완료/오류 | success / error + Soft | 상태를 텍스트로도 안내 |

모든 요소를 오렌지로 강조하지 않는다. 브랜드 보라색을 임의 배경·그라데이션으로 확장하지 않는다. disabled는 비활성 전용이며 본문·설명에 쓰지 않는다. dark mode·유리 효과·입체 버튼·새 그라데이션 금지.

## 7. 깊이·인터랙션

기본 구분은 회색 바탕/흰 표면/내부 inset으로 만든다. 홈 주요 카드만 0 4 16 / 약4% 그림자, 시트는 0 16 48 / 약16%. 모든 카드에 그림자를 추가하지 않는다. 취소는 명시적 확인 시트 후 실행하고 실패 시 기존 신청 상태를 보존한다.

현재 Figma가 정의하지 않은 focus/loading/error 구현에는 기존 색/간격을 재사용한다. 전달용 focus 규칙은 ink 2px outline +4px offset이다. 이것은 접근성 구현 보완 규칙이며 원본 Figma 토큰으로 가장하지 않는다. 시트 포커스 고정·Escape닫기·닫은 후 트리거 복귀, 버튼 키보드 조작을 구현한다.

## 8. 변경과 검수

색상 값이 같아도 페이지 파일에 hex를 쓰지 않는다. 의미 토큰 또는 승인된 클래스를 쓴다. 다른 UI 키트의 기본 테마는 끈다. 컴포넌트가 부족하면 승인된 기존 패턴으로 해결 가능한지 먼저 확인하고 불가능한 패턴만 변경안으로 올린다.

변경안에는 대상 화면/기존값/제안값/필요한 이유/비교 캡처를 포함한다. 승인 후에만 기준 버전과 잠금 해시를 함께 갱신한다. 새 디자인이 예쁘다는 이유는 기존 계약을 바꾸는 근거가 아니다.


## 아이콘 구현 연결

원본 SVG는 reference 용도로 보존했다. `assets/icons.svg`는 같은 경로를 currentColor로 정규화한 구현용 스프라이트다. `.ax-nav-link` 안에 `.ax-icon` SVG와 `<use href=".../assets/icons.svg#nav-home">`을 배치한다. 나머지 키는 nav-program, nav-experience, nav-my. 각 SVG는 aria-hidden="true", 버튼/링크에는 실제 기능 이름을 제공한다. img로 원본 SVG를 직접 넣으면 원본 선택 색이 고정되므로 선택 상태 구현에는 스프라이트를 쓴다.

QR은 `.ax-qr` 안에 32px 원본 qr-corners.svg 이미지와 `.ax-qr-label`의 QR 텍스트를 겹친다. 버튼 접근성 이름은 '내 QR 보여주기'. Q02 활동 QR 스캔과 구분한다.
